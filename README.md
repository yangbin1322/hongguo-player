## 🖥️ 为什么做这个?

手机刷短剧很方便. 但已经坐在电脑前的时候, 为了看几集还要拿起手机, 或者专门开一个安卓模拟器, 多少有点麻烦.

所以做了这个真正适合电脑用的红果短剧客户端: 鼠标滚轮刷剧, 方向键切换, 看完自动下一集, 还能开个小窗边工作边追剧.

## ✨ 主要功能

- 🎬 **沉浸式刷剧**: 推荐 / 分类刷剧, 鼠标滚轮或方向键切换, 边刷边预加载
- ▶️ **自动连播**: 看完自动播放下一集、下一季, 记住上次看到哪
- 🔍 **找剧方便**: 搜索 (带输入联想)、多维度筛选、排行榜、新剧推荐与上新日历
- 💬 **互动**: 弹幕 (点赞 / 回复 / +1)、评论与剧评, 和手机端互通
- ❤️ **追剧管理**: 收藏、点赞、观看历史、预约, 都能搜索和批量删除
- 🪟 **小窗模式**: 窗口置顶, 边工作边追剧; 隐身模式下鼠标移开自动暂停隐藏
- 🙈 **干净的画面**: 鼠标不动时控制条、点赞栏自动隐藏, 全屏看剧不挡画面
- 🔗 **分享**: 一键复制分享链接 (手机红果 App 可直接打开); 复制别人的分享链接后自动识别播放
- 💻 **Windows + macOS**: Mac 同时支持 Intel 与 Apple 芯片
- ⚡ **解码兜底**: 硬件解码不可用时自动改用软件解码, 不会只有声音没有画面
- 🔄 **自动更新**、浅色 / 深色主题

## 📥 下载与安装

| 系统 | 下载 | 文件 |
|---|---|---|
| Windows 10 / 11 (64 位) | [下载 Windows 版](https://hongguo.235698.xyz/download/latest/windows-amd64) | `hongguo-版本号-windows-amd64.exe` (Releases 里另有 zip) |
| macOS (Intel 与 Apple 芯片通用) | [下载 macOS 版](https://hongguo.235698.xyz/download/latest/darwin-universal) | `hongguo-版本号-macos-universal.zip` |

下载慢可以到本仓库的 [Releases](../../releases/latest) 下载同样的文件.

**Windows**

1. 下载后直接双击 `.exe` 运行, 无需安装 (下载的是 zip 就先解压, 再双击 `红果短剧.exe`). 以后有新版本时程序会提示, 点 "立即重启更新" 即可自动更新.
2. 若提示 "Windows 已保护你的电脑", 点 **更多信息 → 仍要运行** (程序没有购买代码签名证书).
3. 首次运行如果系统缺少 **WebView2 运行时** 或 **HEVC 视频扩展**, 程序会自动安装 (WebView2 需要联网).

**macOS**

1. 解压得到 `红果短剧.app`, 拖到 "应用程序".
2. 应用未签名, 首次打开如提示 "已损坏" 或 "无法验证开发者", 在终端执行:
   ```
   xattr -cr /Applications/红果短剧.app
   ```
   然后再打开.

## ❓ 常见问题

**需要登录吗? 要钱吗?**

免费, 不登录也能刷剧; 收藏、点赞、观看历史未登录时保存在本机. 用手机号登录后与手机端红果 App 同步.

**只有声音, 没有画面?**

1.1.5 起硬件解码不可用时会自动改用软件解码, 一般不会再出现; 旧版本请先更新. 仍有问题可按下面排查:

1. 点播放器提示条上的 **"重启程序"**. HEVC 视频扩展刚装上或被微软商店更新后, 要重启程序才能生效.
2. 仍不行就**重启电脑**再试.
3. 扩展自动安装失败时, 程序会把安装包 `HEVC视频扩展-双击安装.appx` 放到程序目录, 双击手动安装.
4. 远程桌面 / 虚拟机通常没有显卡硬件解码, 会使用软件解码 (CPU 占用较高); 画面花屏 / 黑屏时可在弹幕设置里勾选 "软件解码".

**遇到问题怎么反馈?**

在程序左侧点 **"反馈"** 提交 (可留邮箱, 解决后通知你), 或到本仓库提 [Issue](../../issues), 也可以加 QQ 联系作者.
